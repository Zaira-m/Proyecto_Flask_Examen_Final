# Proyecto Flask – Examen Final  
**Asignatura:** Programación Web  

---

## 📌 Descripción  
Este proyecto corresponde al **Examen Final** de la asignatura *Programación Web* y fue desarrollado utilizando el framework **Flask**.  
La aplicación incluye un menú principal y dos ejercicios funcionales:

### 🧩 Ejercicio 1 – Compra de Tarros de Pintura  
- Calcula el total a pagar según la cantidad de tarros ingresados.  
- Aplica descuentos según la edad del cliente.  
- Muestra un resumen detallado de la compra.

### 🔐 Ejercicio 2 – Inicio de Sesión  
- Permite validar un usuario y contraseña.  
- Muestra mensajes personalizados según credenciales válidas o inválidas.

---

## 📂 Estructura del proyecto

- **main.py** → Archivo principal que ejecuta la aplicación Flask.  
- **/templates** → Contiene las páginas HTML del proyecto.  
  - `index.html` – Menú principal  
  - `ejercicio1.html` – Compra de pintura  
  - `ejercicio2.html` – Inicio de sesión  
  - `acerca.html` – Información del proyecto  
  - `base.html` – Plantilla base con barra de navegación  
- **/static** → Archivos CSS (estilos del sitio).  
- **requirements.txt** → Dependencias necesarias para ejecutar el proyecto.

---

## 🛠 Tecnologías utilizadas

- Python 3  
- Flask  
- HTML, CSS
